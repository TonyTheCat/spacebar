Spacebar

You are setting this up for somebody who will not see this page. Do it once, together, and from then on the browser opens, connects and talks by itself.

1. The OpenAI key

Spacebar speaks through OpenAI's realtime service, which needs a key. It stays in this Chrome profile and is sent nowhere except to OpenAI. It is never shown back here.

2. The microphone

Chrome asks for the microphone once, in a dialog. Answer it now, while you can see it — otherwise the first thing they say goes into a box they cannot find.

3. Where the browser opens

Chrome's own new-tab page is empty for a voice: nothing runs there, so the space bar does nothing. Spacebar opens a real site instead. Leave this empty for Google, or name a site the way you would say it out loud — the same words work when they say "open …".

4. The language they speak

Pick the language the person actually speaks. Left to guess, transcription can hear English as something else, and the errand goes the wrong way with nothing to say why. English if you leave it alone.

Done? Close this tab. Next time Chrome starts, a pinned tab opens on its own and says where it is.
